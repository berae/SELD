## 11项统计与方法风险检查

总体边界为CAUTION；11/11检查，非有效性认证。

| 检查 | 证据与限制 |
|---|---|
| Simpson反转 | 已看逐baseline、静态/动态及无pair分层；平滑存在总体/子组差异，未穷尽房间/类别 |
| 生态谬误 | 只描述三个权重，不推广到每条录音或跨数据集；头seed稳定性单列 |
| Berkson选择 | 固定匹配有选择性，保留全GT、漏检与未匹配分母，不说覆盖全部目标 |
| Collider偏差 | GT仅作监督和离线诊断，不进入推理历史关联或作为因果控制 |
| 基率忽略 | 同时保留静态/动态、motion pair及全部匹配的基数 |
| 均值回归 | 披露validation选优及历史evaluation暴露，不按evaluation再选权重 |
| 幸存者偏差 | 八头、14条件全保留；旧导出和预检失败、连接中断均留档 |
| 多重比较 | 完整保留预登记比较，不新增p值或筛选后显著性主张 |
| 分析路径 | 网络/损失不变，只修导出上下文和预检夹具；先八头冻结再评估 |
| 相关与因果 | 消融均值差不等于机制证明；历史容量差、单数据集和小样本限制明确 |
| 反向因果 | 前缀测试仅检验覆盖范围内的时序约束，不据此建立因果机制结论 |
